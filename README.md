# 政理｜考研政治概念自学

一个纯静态、以理解为中心的政治概念自学网站。项目不以刷题和应试技巧为重点，而是通过**定义、直觉、理论推导、现实联系、用途与边界**，帮助学习者理解概念本身及其相互关系。

## 项目目标

- 按马原、毛概、史纲、思修、时政五大板块组织内容。
- 用清晰、准确且易于理解的语言解释政治概念。
- 将抽象理论与历史情境、社会现象和个人经验联系起来。
- 提供概念搜索、收藏、导航和深色／浅色模式等自学辅助功能。
- 无需后端、数据库或构建工具，可直接部署到 GitHub Pages。

## 使用说明

### 本地查看

直接用浏览器打开 `index.html` 即可查看页面结构。待样式与脚本文件补充完成后，也可以在项目根目录启动本地静态服务器：

```bash
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```

除 Font Awesome 图标通过 CDN 加载外，项目资源均使用相对路径引用。没有构建步骤，也不需要安装依赖。

### 学习方式

每个概念按以下路径展开：

1. **概念定义**：明确概念的含义及核心关系。
2. **直觉理解**：借助类比或日常经验形成直观认识。
3. **理论推导**：呈现概念成立的前提与推理过程。
4. **现实联系**：将理论放入历史、社会与个人实践情境。
5. **用途与边界**：说明概念能帮助分析什么，以及不能如何误用。

### 部署到 GitHub Pages

1. 将项目文件推送到 GitHub 仓库。
2. 打开仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 选择目标分支和 `/ (root)` 目录并保存。
5. 部署完成后，通过仓库对应的 GitHub Pages 地址访问。

## 如何贡献

欢迎补充概念内容、修正表述、改善可访问性或完善交互体验。

1. Fork 仓库并创建新的功能分支。
2. 保持现有纯静态结构，不引入后端或不必要的框架。
3. 概念内容应归属明确的板块，并尽量覆盖定义、直觉、推导、现实联系及用途边界。
4. 理论表述力求准确；时政内容应注明发生时间与可靠来源，避免使用无出处的材料。
5. 新增资源使用相对路径，确保项目部署在 GitHub Pages 子路径下仍可访问。
6. 提交前检查导航、搜索、收藏、键盘操作和深浅色模式，并验证常见屏幕宽度下的显示效果。
7. 提交 Pull Request，说明修改内容、原因及验证方式。
